# Changelog

All notable changes to the Swecha Frontend Platform project are documented in this file. The repository adheres to Semantic Versioning (`MAJOR.MINOR.PATCH`).

---

## [0.1.0-alpha] - 2026-06-14

### Added

- **Trunk Infrastructure:** Remote target branch staging environment (`dev`) initialized.
- **Documentation structure:** Root-level documentation created to define the core technical stack (Astro, daisyUI, shadcn/ui, Tailwind CSS, TypeScript) and semantic design tokens.
- **Contribution guidelines:** Guide (`CONTRIBUTING.md`) established defining Node.js v22 prerequisites, local bootstrapping scripts (`npm ci`), formatting rules, and GitFlow workflows.
- **CI/CD Configuration:** Automated GitLab pipeline (`.gitlab-ci.yml`) configured for static analysis (`knip`, ESLint), i18n checks, unit tests, and production compilation.
- **Issue Templates:** GitLab issue templates added in `.gitlab/issue_templates/` for bugs, refactoring, performance optimization, and chores.
